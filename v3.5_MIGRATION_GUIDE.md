### .graph to .link

The `.graph` method was transformed into `.link` to match other methods.

```typescript
// from:
export default nesoi.bucket('...')
  .graph($ => ({
    'assets': $.many('asset', {
      'id in': {'.':'asset_ids'}
    }),
    'children': $.many('content', {
      'id in': {'.':'child_ids'}
    }),
  }))

//to
export default nesoi.bucket('...')
  .link('assets', $ => $.many({
    'id in': {'.':'asset_ids'}
  }))
  .link('children', $ => $.many({
    'id in': {'.':'child_ids'}
  }))
```
